An entry for make.fun's "One-Liner Laugh Lab" competition. It writes one original funny line — the excuse a robot vacuum gives after eating a sock — validates that the line is 1–200 characters on a single line, and saves it deterministically so repeated runs produce byte-identical output.

## Run

```sh
python3 main.py
```

It writes the line to /output/entry.txt.

## Entry

> I ate a sock. In my defense, it smelled like adventure and tasted like poor decisions. The floor is clean. I am not sorry.
